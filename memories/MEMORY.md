配置备份：公开仓库 anlen123/hermes-config，克隆在 `~/.hermes/hermes-config/`，同步跑 `python hermes-config/scripts/sync-hermes-config.py`（先 `--dry-run` 过两道脱敏闸门）。本机放有 `~/.hermes/.sync-no-skills`，故**本机不参与技能备份** —— 仓库 skills/ 由别的机器维护，本机既不推也不删。在 Windows 上跑该脚本必须显式给 subprocess 传 `encoding="utf-8"`，否则 GBK 解码会让 git 输出静默变 None。
