初始 7 类由用户 2026-10 确认；无匹配时归 `📦其他` 并让用户决定要不要新建。

## 匹配规则

1. **最长关键词优先**：同一段话里命中多个类型时，取命中关键词最长的那个。
   - `吃面` (2) 胜过 `面` (1) → 🍚外面吃饭
   - `夸克网盘会员` 命中 夸克/网盘/会员 (各 2) → 🎫订阅会员
   - 长度相同时按表内顺序（靠前优先）。
2. ASCII 关键词（`ai`、`api`、`gpt`…）用词边界匹配，`api` 不会误命中 `ai`。
3. 用户说「AI充值」时 `ai充值`(4 字) 直接胜出，不会被别的类型抢走。

## 加新类型的步骤

1. 在 `CATEGORIES` 里插入（放前面 = 同分优先），至少给 `name` / `emoji` / `keywords`；
   emoji 挑一个语义清晰、和现有不撞的（如「🐶宠物」「🎁人情」「📚学习」）。
2. `python -m py_compile scripts/ledger.py` 确认语法；
3. 用 `LEDGER_DIR` 指向临时目录跑一笔验证命中（别拿真账本试）；
4. 用户那笔历史记录用 `ledger.py edit <编号> --category 新类型` 修正，或 `--month` 指定月份。
5. 顺手把新类型的常用说法补进 keywords，不要只留一个词。

## 已知的模糊地带（用户没定的）

- 水/电/燃气/物业费 → 暂放 📶话费网络（生活缴费语义最近）。
- 零食 → 买菜（超市采购），若用户要求单列则新建「🍿零食」。
- 房租、大件家电、转帐、人情往来 → 目前会落到 📦其他，按用户反馈再决定是否立类。
