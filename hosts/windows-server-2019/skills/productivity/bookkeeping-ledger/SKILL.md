# 记账本（个人账目）

用户说「记账 XXX」时，把 XXX 解析成金额/类型/日期/备注并追加到本机账本；说「看账本」时按月打印账目表。
全部逻辑在一个纯标准库脚本里，模型只负责转发脚本输出，不自己算数。

## When to Use

- 「记账 买菜 66.47 买西瓜」「记一笔 打车 23」「记账 早上买早饭 5.5」
- 「看账本」「本月账目」「9月账目」「账本汇总」
- 「这个月各类型花多少」（→ `stats`）
- 「#12 的详情/原话是什么」→ `ledger.py show 12`（跨月 `show u44`）：一次打印日期/类型/金额/备注/**原话**/登记时间/来源
- 「删掉 #11」「把 #11 金额改成 90」「把 #11 备注改成买西瓜」
- 「把这个 CSV 导进账本」「记账明细导进来」（见下「批量导入 CSV」）
- 不要用于：发票/截图识别、别人家账目分析、投资记账（这个账本只管日常流水）

## 数据与路径

| 项 | 位置 |
| --- | --- |
| 脚本 | `C:/Users/Administrator/AppData/Local/hermes/skills/productivity/bookkeeping-ledger/scripts/ledger.py` |
| 账目数据 | `C:/Users/Administrator/AppData/Local/hermes/ledger/ledger.jsonl`（JSONL，一条一行，只追加） |
| 配置 | `C:/Users/Administrator/AppData/Local/hermes/ledger/config.json` → `{"numbering": "monthly"}` |

`numbering` 语义：`monthly`（默认，表格编号 = 当月第 N 笔，跨月重新从 1 开始）/ `global`（跨月连续累加）。
切换：`ledger.py config --numbering global`。
改目录只用于测试：环境变量 `LEDGER_DIR`。

## 铁律（先读这三条）

1. **一切数字来自脚本 stdout，原样转发**。不要自己算合计、不要自己推算今天日期 —— 脚本内部读系统时间（`datetime.now()`）。
2. **金额没解析出来**（退出码 2，提示「❓没识别出金额」）→ 直接问用户「这条记的是多少钱？」，**绝不猜金额**。
3. **只有「记账」类指令才写数据**。报表/查询/汇总都是只读，不要顺手补记。

## 记账流程

把用户原话（去掉「记账」两字后剩的内容）整体作为**一个双引号参数**传给 `add`，中文原样，不要改写、不要拆词：

```
terminal(command='python "C:/Users/Administrator/AppData/Local/hermes/skills/productivity/bookkeeping-ledger/scripts/ledger.py" add "买菜 66.47 买西瓜"')
```

输出示例（这就是要回给用户的**全部**内容，不要再加表格）：

```
✅ 已记账 #12 · 10-07 🥬买菜 66.47 元｜备注：买西瓜｜2026年10月 12 笔 共 415.84 元
📝 原话：买菜 66.47 买西瓜（早市）
```

**第二行 `📝 原话` 必须转发**：账本把用户原话原样存在条目 `raw` 字段（不做全角归一化），并在收据里回显；用户明确要求过“记账时要把原话记录下来”。原话为空的条目（旧数据）不输出这一行。

- 脚本自己会认：阿拉伯数字/全角数字/中文数字（一百块）、`¥`、`66.47元`、**角零头写法** `5块5` / `5元5角` / `5块5毛` / `16块47` / `12块50`（=5.50 / 5.50 / 5.50 / 16.47 / 12.50；一位零头=角，两位=角分）；跳过 `3斤`、`10月2日` 里的数字，也跳过 `5块 3斤` / `10块 2个` 这种「整元+数量」（取 5.00 并把数量留在备注）。
- 时间词：`昨天`/`前天`/`大前天`/`10月2日`/`2026-10-02` 都能识别，没写日期就用当天。
- 若输出多出第二行 `⚠️ 类型没匹配上，暂记「📦其他」…`，**一并转发**，并问用户要不要新建类型。
- 用户补一句类型（如「叫外卖」）时：改脚本 `CATEGORIES` 的 keywords/emoji（见 `references/categories.md`），然后用 `ledger.py edit <编号> --category 新类型` 修正那一笔。

完成判据：回给用户的消息里恰好一行 ✅ 收据 + 一行 📝 原话（+ 可选的 ⚠️ 一行）。

## 看账本流程

| 用户说法 | 命令 |
| --- | --- |
| 本月账目 / 看账本 | `report` |
| 9月账目 / 2026-09 | `report --month 2026-09` |
| 账本汇总 / 每个月的 | `report --all` |
| 各类型花多少 | `stats --month 2026-10` |
| 表格在 QQ 里显示乱 | 加 `--format plain`（每笔一行纯文本） |
| 某一笔的原话 / 详情 | `show 12`（当月编号）或 `show u44`（跨月） |

把 stdout **整块**转发（就是表头 `2026年10月账目（N 笔，共 X 元）` + Markdown 表 + 点评两三行），不要重排、不要改数字。
用户说「9月」而没给年份时，用当前年份拼 `YYYY-09`。

完成判据：表头「N 笔，共 X 元」与表内明细一致（脚本保证，但转发前扫一眼有没有丢行）。

## 批量导入 CSV

用户发来导出的账表明细（列：`编号,日期,收支,类型,金额（元）,备注,登记时间`）时：

1. **先预演**：`ledger.py import-csv "<path>" --dry-run` —— 把 stdout 原样转给用户确认（笔数/月份/类型/跳过数），**不要直接写盘**。
2. 用户点头后再跑一次去掉 `--dry-run` 的命令。
3. 只导某月用 `--month 2026-10`（不写则全导）。

细节与坑：

- **幂等**：条目带 `src:{file,no}`，同一文件重复导入只会「重复跳过 N」。
- 列名宽容（`金额（元）`/`金额`、BOM 自动处理），日期支持 `2026/9/22`、`2026-09-22`。
- **CSV 的「编号」不沿用**：表格编号仍按 `numbering` 规则重排（monthly=当月第 N 笔），原编号只留在 `src` 里。转发预演时要主动跟用户说明这点。
- 非「支出」行默认跳过并计数（账本只记支出）；金额 ≤0 或日期解析失败也计入「无法解析」。
- CSV 里出现类型表（`CATEGORIES`）没有的类型，先补进去（emoji + 关键词），否则报告里只显示 📦；预演会打印 `⚠️ 类型表里没有：...`。
- 导入顺序按 (日期, 登记时间, 原编号) 排，uid 与时间线一致。
- 导入条目的 `raw`（原话）= **CSV 原始行**（用 `｜` 拼全部单元格）；所以导入条目也能用 `show` 看到原始行。原话保留的是导入当时的值，之后改分类不会改它（可当审计痕迹）。

## 改 / 删

- `#N` 指**当月第 N 笔**（表格里的编号）：`delete 11`、`edit 11 --amount 90`、`edit 11 --note 买西瓜`、`edit 11 --category 订阅会员`。
- 跨月引用用全局 UID：`u44`（`search` 结果里显示的 `u**` 就是它）。
- 删除后当月编号会自动压实（后面每笔减 1），这是预期行为。
- 破坏性操作（删除）**先复述再执行**：「删掉 #11（10-07 🥬买菜 66.47 买西瓜），确认？」等用户点头再跑 `delete`。

## Pitfalls

- **路径必须用 `C:/...` 正斜杠原生形式**。MSYS 的 `/c/Users/...` 会被 Python 当相对路径，写出 `C:\c\Users\...` 的鬼目录。
- 用户只发「记账 买菜」这种没金额的：不是错误，是缺信息 —— 问金额，别瞎填。
- 别给 `add` 加 `--now`，那是测试用假日期；日常必须用系统时间。
- 备注里保留「早上」「家里常备」这类描述词是有意的；只有「记账/一笔/元」这类填充词会被清掉。
- 金额走 `parse_amount`：优先级 `块/元+角零头`(100) > `带单位后缀`(99) > `¥前缀`(98) > 裸数字(50) > 中文数字(40)，同优先取靠右的。新增金额写法先补 `CURRENCY_*` 正则，改完拿 `LEDGER_DIR=<临时目录>` 跑一组例子里试（`unset LEDGER_DIR` 别忘了）。
- 类型判定是「最长关键词优先」：`吃面`(2) 赢 `面`(1)，`夸克网盘会员` 归订阅会员。关键词冲突时，改 `CATEGORIES` 里更长的关键词而不是调顺序。
- **`LEDGER_DIR` 会跨命令残留**：terminal 会话共享环境变量，测试时 `export LEDGER_DIR=...` 之后必须 `unset LEDGER_DIR`，否则真实记账也写进测试目录（曾因此以为「文件不落盘」白查一轮）。动账本前先 `echo $LEDGER_DIR` 确认为空。
- 数据文件是 JSONL，别手工改成 JSON 数组；追加写入保证不丢历史。

## Verification

1. 记账后：`search <关键词>` 能查到刚记的那笔，金额/日期与收据一致；`echo $LEDGER_DIR` 为空时，文件应落在 `C:/Users/Administrator/AppData/Local/hermes/ledger/ledger.jsonl`。
2. 报表：`report --month YYYY-MM` 表头笔数、合计与用户预期一致；空月份输出「还没有账目。」而不是报错。
3. 脚本健康检查：`python -m py_compile <脚本路径>` 无输出即语法正常。
