# 模型单价对比（人民币）

用户会问「A 和 B 谁更便宜」「用人民币算」，或要按成本挑供应商/模型来切。
目标产物是**一张人民币对照表 + 一句结论 + 会翻转结论的因素清单**，数据必须来自官方定价页，不能凭记忆报价。

## 步骤

1. **认定官方价的准确模型名**：口语名 ≠ 模型 ID（「glm5.3flash」→ `glm-5.3-flash` / 聚合商上的 `z-ai/glm-5.3-flash`）。
   不确定就先列聚合商目录（`GET /api/v1/models`，返回 ID 与每 token 单价）反查真实 ID。
2. **逐个取官方定价页**（见下表），别用第三方博客或评测文的数字。
3. **统一换算到人民币**：`https://open.er-api.com/v6/latest/USD`（无需密钥，返回 `rates` 与更新时间），
   报出汇率取值与日期。国内站本身按人民币计价就直接用原值，不要换算。
4. **出表**：列「输入 / 缓存命中 / 输出」（元每百万 tokens），标出官方原价；再给一张以最便宜者为 1 的倍数表；
   最后给一个混合场景（如输入 10 : 输出 1）的加权成本，把「按什么用法」讲清楚。
5. **附上会翻转结论的因素**（见下），并注明数据来源与汇率日期。

## 各家定价页入口（都实测可取）

| 供应商 | 取法 |
|---|---|
| OpenAI | `https://platform.openai.com/docs/pricing` 的 markdown 版：路径后加 `.md`（`/docs/pricing.md`）→ 干净的表格，一次含 Standard / Batch / Flex / Fast 四档 |
| 智谱国内站 | Mintlify 文档站：先取 `https://docs.bigmodel.cn/llms.txt` 拿全站索引，再对目标页加 `.md`，价格页是 `/cn/guide/start/pricing.md`（**人民币原价**） |
| Z.AI 海外站 | 同法，`https://docs.z.ai/guides/overview/pricing`（**美元**，与国内站不是同一套价） |
| DeepSeek | `https://api-docs.deepseek.com/quick_start/pricing` 静态渲染，HTTP 抓下来剥标签即可；中英文页都是美元计价 |
| 聚合商 | `GET https://openrouter.ai/api/v1/models`，`pricing.prompt` / `pricing.completion` 是每 token 美元价，带 `:batch` 后缀的是批量档 |

## 取数技巧与挡路的站点

- **Mintlify 文档站**（智谱、Z.AI）：`/llms.txt` 是官方全站索引，`<页面>.md` 直出 markdown —— 比爬 HTML 又快又准。
- **纯 JS 的 SPA 价格页**（`open.bigmodel.cn/pricing`）返回的是「请开启 JavaScript」空壳，`r.jina.ai` 抓回来也是同一句 ——
  别在这上面耗，转文档站的 `.md`。
- **搜索引擎被 bot 墙挡住时**：DuckDuckGo 的 `html.duckduckgo.com` 会返回人机校验页；
  `https://www.bing.com/search?q=<urlencoded>&setlang=zh-CN` 配普通浏览器 UA 能正常返回结果列表，
  用来找「官方文档域是哪个」很有效。
- 别用 `curl -o /tmp/...` 存中间结果（本机 MSYS 路径不转换会静默失败）；要在本地落盘就用原生
  `C:/Users/...` 形式的路径，或干脆在 Python 里 `urllib` 取到内存。

## 会翻转「谁更便宜」的坑

- **峰谷价**：DeepSeek 高峰时段价格翻倍 —— UTC 01:00–04:00 与 06:00–10:00、周一至周五
  （= 北京时间工作日 09:00–12:00、14:00–18:00）；其余时间含周末与中国法定节假日全天是低谷价。
- **缓存命中价**：各家能差一个数量级（DeepSeek 的命中价远低于智谱）。长系统提示词、反复读同一批文件的 agent 任务里，
  命中价占大头，结论可能从「A 便宜」翻成「B 便宜」—— 报单价比的时候必须把这一列列出来。
- **长上下文分档**：同一模型超阈值后输入翻倍、输出上调（如某旗舰档短/长上下文是 $2/$10 与 $4/$15）。
  报一个「单价」前先确认用户用量落在哪一档。
- **批量/Flex 档**：聚合与官方常给五折，但打完折仍可能贵过别家的标准价 —— 要一起报。
- **国内站 vs 海外站**：同一家（智谱）国内站按人民币计价，通常比海外美元站便宜两成上下；
  聚合商（OpenRouter）多与海外站同价再加一跳中转。所以「换成某聚合商」几乎总比直连国内站贵，
  值得在切换方案里点明差价比例，让用户自己权衡中转与成本。

## 输出形态（这位用户的偏好）

结论先行一句 → 人民币对照表（输入 / 缓存命中 / 输出）→ 倍数表 → 混合场景成本 → 风险与翻转因素 →
来源与汇率日期。数字之外的缩写要写全或配中文说明（裸的 ETA、MB 之类会被逐条挑出来）。
